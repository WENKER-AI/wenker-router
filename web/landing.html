01
Cài đặt
npm install -g wenker-router rồi gõ wenker. Node.js ≥ 18 là đủ.

          
02
Trỏ Base URL
Cấu hình http://localhost:3600/v1 trong Cursor, Claude Code, Cline hay OpenWebUI.

          
03
Gọi model
Dùng tên provider/model để định tuyến chính xác, hoặc alias miễn phí để router tự phân giải.

          
04
Quan sát & tối ưu
Xem nhật ký, ping độ trễ, chỉnh chuỗi dự phòng — mọi thứ trong dashboard trình duyệt.

Biến môi trường

          

            

              
BiếnMặc địnhDùng để

              
                
PORT3600Cổng lắng nghe của gateway.

                
HOST0.0.0.0Địa chỉ bind. Đặt 127.0.0.1 nếu chỉ dùng nội bộ.

                
WENKER_HOME~/.wenkerThư mục cấu hình, key, nhật ký, cache.

                
WENKER_ADMIN_OPEN_LOCALHOST11: API quản trị mở cho máy cục bộ; 0: bắt buộc key admin.

              
            

          

        

      

    


    
    

      

        Từ khóa, endpoint đến gỡ lỗi
        
Tài liệu, gói gọn
trong một trang.

        

          
01
Kiến trúc & khái niệm
Một tiến trình Node.js vừa là API gateway vừa là dashboard. Ba khái niệm: Provider, Alias, Qualified id (providerId/model).

          
02
Cấu hình & key
Mở dashboard → tab Nhà cung cấp → chọn card → sửa cấu hình. Mọi thứ nằm trong ~/.wenker (đổi bằng biến WENKER_HOME).

          
03
API tham chiếu

            
    
              
  • POST /v1/chat/completionsTrò chuyện (OpenAI)
    • 
              
  • POST /v1/messagesTrò chuyện (Anthropic)
    • 
              
  • GET /v1/modelsLiệt kê model
    • 
              
  • POST /v1/embeddingsVector hoá
    • 
              
  • GET /healthHealth JSON
    • 
            

          

          
04
Tích hợp công cụ
Claude Code: đặt ANTHROPIC_BASE_URL. Cursor / Cline / OpenWebUI / Aider: chọn OpenAI Compatible. VS Code: extension WENKER nạp thẳng model của router.

          
05
Bảo mật & mạng
Mặc định bind 0.0.0.0 để thiết bị trong LAN cùng dùng; API quản trị chỉ tin vòng lặp cục bộ trừ khi bạn truyền admin key.

          
06
Gỡ lỗi
401/402 = key sai hoặc hết tiền; 429 = đổi nguồn trong chuỗi dự phòng. Router liệt kê model của mọi provider đã bật — kể cả nguồn chưa gắn key.

        

        

          
          
$ curl http://localhost:3600/v1/chat/completions \
  -H "Authorization: Bearer sk-wenker-local-admin" \
  -H "Content-Type: application/json" \
  -d '{"model":"wenker-cloud/wenker-deepseek-v3-free","messages":[{"role":"user","content":"Xin chào"}]}'

        

        

          
Câu hỏi thường gặp

          
Model “miễn phí” có thật sự miễn phí không?
Không phải lúc nào cũng vậy. Hàng chờ miễn phí có hạn mức và có thể trả về 402/502 thật. Muốn ổn định, hãy gắn key của nhà cung cấp đó.

          
Tôi có buộc phải dùng key mặc định trong README không?
Không. Mọi key đều do bạn tự cung cấp; router chỉ giữ và dùng chúng trên máy bạn.

          
Sao lưu / di chuyển cấu hình thế nào?
Copy nguyên thư mục ~/.wenker. Đó là toàn bộ “database”.

          
Có an toàn khi mở cổng 0.0.0.0?
API quản trị chỉ chấp nhận request từ vòng lặp cục bộ theo mặc định; endpoint /v1/* dùng key WENKER riêng.

          
Sao một số model trong danh sách báo chết?
Router liệt kê model của mọi provider đã bật — kể cả nguồn bạn chưa gắn key. Đó là tính năng minh bạch, không phải lỗi.
