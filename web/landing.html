        Từ khóa, endpoint đến gỡ lỗi
        
Tài liệu, gói gọn
trong một trang.

        

          
01
Kiến trúc
Một tiến trình Node.js vừa là API gateway vừa là dashboard. Ba khái niệm: Provider, Alias, Qualified id (providerId/model).

          
02
API tham chiếu

            
    
              
  • POST /v1/chat/completionsTrò chuyện (OpenAI)
    • 
              
  • POST /v1/messagesTrò chuyện (Anthropic)
    • 
              
  • GET /v1/modelsLiệt kê model
    • 
              
  • POST /v1/embeddingsVector hoá
    • 
              
  • GET /healthHealth JSON
    • 
            

          

          
03
Tích hợp công cụ
Claude Code: đặt ANTHROPIC_BASE_URL. Cursor / Cline / OpenWebUI / Aider: chọn OpenAI Compatible. VS Code: extension WENKER nạp thẳng model của router.

          
04
Gỡ lỗi
401/402 = key sai hoặc hết tiền; 429 = đổi nguồn trong chuỗi dự phòng. Router liệt kê model của mọi provider đã bật — kể cả nguồn chưa gắn key.

        

        

          
          
$ curl http://localhost:3600/v1/chat/completions \
  -H "Authorization: Bearer sk-wenker-local-admin" \
  -H "Content-Type: application/json" \
  -d '{"model":"wenker-cloud/wenker-deepseek-v3-free","messages":[{"role":"user","content":"Xin chào"}]}'

        

        

          
Model “miễn phí” có thật sự miễn phí không?
Hàng chờ miễn phí có hạn mức và có thể trả về 402/502 thật. Muốn ổn định, hãy gắn key của nhà cung cấp đó.

          
Sao lưu / di chuyển cấu hình thế nào?
Copy nguyên thư mục ~/.wenker. Đó là toàn bộ “database”.

          
Có an toàn khi mở cổng 0.0.0.0?
API quản trị chỉ chấp nhận request từ vòng lặp cục bộ theo mặc định; endpoint /v1/* dùng key WENKER riêng.
