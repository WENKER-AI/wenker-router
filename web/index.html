Vì sao chọn WENKER Router?

Không dịch vụ trung gian, không khóa tài khoản. Dữ liệu và key của bạn nằm trên máy bạn.

Định tuyến

Một model id, mọi nguồn dự phòng

Gọi bằng tên thân thiện; router phân giải sang model thật, tự fallback theo thứ tự bạn đặt, và ghi rõ nguồn nào thực sự trả lời.

  • SMART FALLBACK
  • CIRCUIT BREAKER
  • MODEL ALIAS
  • NGUỒN THẬT ĐƯỢC GHI RÕ
Tương thích

Trỏ Base URL về máy bạn là xong

Cursor, Cline, Roo Code, Claude Code, OpenWebUI, Aider — cả chuẩn OpenAI lẫn Anthropic, gồm streaming SSE truyền thẳng.

  • OPENAI /V1
  • ANTHROPIC /V1/MESSAGES
  • SSE STREAMING
  • PLAYGROUND THU MODEL
Quyền riêng tư

Key và dữ liệu không rời máy bạn

Zero database: mọi thứ là file JSON trong ~/.wenker. Key upstream được che khi hiển thị; API quản trị khóa theo vòng lặp cục bộ.

  • ZERO DATABASE
  • SAO LƯU = COPY MỘT THƯ MỤC
  • KEY ĐƯỢC CHE
  • KHONG TELEMETRY
Vận hành

Số liệu thật, đo từ instance đang chạy

Dashboard quản lý key, ping độ trễ, probe nguồn sống thật; mỗi request ghi lại provider, model đích, token và cờ cache.

  • PROBE NGUỒN THẬT
  • PING ĐỘ TRỄ
  • NHAT KY REQUEST
  • ADDON / THEME
Nói thẳng về bản miễn phí: các “tier” WENKER Cloud / VIP là lối tắt cấu hình sẵn, trỏ tới nhà cung cấp bên thứ ba. Nguồn nào cần key thì vẫn cần key của bạn.

Cách tải & cài đặt

Cần Node.js ≥ 18 (để có fetch tạo sẵn). Chọn một cách dưới đây.

Cách nhanh nhất — đóng gói wenker-router (~157 kB, chỉ 3 dependency runtime).

$ npm install -g wenker-router
$ wenker

Lệnh wenker được khai báo qua trường bin trong package.json.

Dành cho người muốn đọc mã nguồn hoặc tự vá.

$ git clone https://github.com/WENKER-AI/wenker-router.git
$ cd wenker-router
$ npm run install:all
$ npm start

Client đã có bản build sẵn trong client/dist; muốn sửa giao diện thì chạy npm run dev:client.

Trên Windows: nhấp đúp start.bat. File kiểm tra Node, mở trình duyệt và bật server.

> start.bat

Chạy thử một lần mà không cài gì cả.

$ npx wenker-router

Tài liệu

Từ khóa, endpoint, tích hợp đến gỡ lỗi — mọi thứ cần để chạy WENKER Router.

01 Kiến trúc & khái niệm

WENKER Router là một tiến trình Node.js duy nhất vừa là API gateway vừa là dashboard.

Ba khái niệm chính: Provider, Alias và Qualified id.

02 Cấu hình & key

Mở dashboard → tab Nhà Cung Cấp → bấm vào card → Chỉnh sửa cấu hình.

Mọi thứ nằm trong ~/.wenker (đổi bằng biến WENKER_HOME).

03 API tham chiếu

Bốn endpoint phủ gần như mọi công cụ.

EndpointDùng để
POST /v1/chat/completionsTrò chuyện.
POST /v1/messagesTrò chuyện chuẩn Anthropic.
GET /v1/modelsLiệt kê model.
POST /v1/embeddingsVector hoá văn bản.
GET /healthHealth JSON.
 
$ curl http://localhost:3600/v1/chat/completions \
  -H "Authorization: Bearer sk-wenker-local-admin" \
  -H "Content-Type: application/json" \
  -d '{"model":"wenker-cloud/wenker-deepseek-v3-free","messages":[{"role":"user","content":"Xin chao"}]}'

04 Tích hợp công cụ

Claude Code CLI: đặt ANTHROPIC_BASE_URL.

Cursor / Cline / OpenWebUI / Aider: chọn OpenAI Compatible.

VS Code: extension WENKER nạp model của router.

05 Bảo mật & mạng

Mặc định bind 0.0.0.0 để thiết bị khác trong LAN dùng.

06 Gỡ lỗi

Model báo chết? Router liệt kê model của mọi provider đã bật.

Lỗi thường gặp: 401/402 = key sai hoặc hết tiền.
